# Querydesk interface

An operating surface for exploring sales data: a persistent database outline on the left and a question, editable SQL, and results in one continuous workspace. An understated blue palette supports long reading sessions. Code uses monospace; explanatory copy uses Segoe UI. No remote fonts or images are needed.

Tokens: canvas #f4f6fa; surface #ffffff; ink #182844; muted #596981; accent #2359c4; line #dce3ef; sidebar #edf2fa. Text sizes: 12, 14, 16, 22, 32px. Layout: 256px sidebar, flexible main content up to 1100px. At 850px the sidebar becomes a collapsible database section. Keyboard focus uses a 3px blue outline. Tables scroll horizontally inside their container.
